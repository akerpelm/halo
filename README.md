# Halo

A spring-physics **Toast**, **Drawer**, **Popover** and **Swipe actions** for React. Toasts keep the speed of your flick, the drawer is a native `<dialog>`, the popover sits on the native popover API, and all four share one frosted-glass material in nine themes.

**[Docs and live demos at haloui.dev →](https://haloui.dev)**

```sh
npm i halo-ui-react
```

```tsx
import { Toaster, toast } from 'halo-ui-react/toast';
import { Drawer } from 'halo-ui-react/drawer';
import 'halo-ui-react/styles.css';

<Toaster />;
toast.success('Invite sent', { description: 'They will get an email shortly' });

<Drawer.Root snapPoints={[0.45, 0.92]}>
  <Drawer.Trigger>Share</Drawer.Trigger>
  <Drawer.Content>
    <Drawer.Handle />
    <Drawer.Title>Share project</Drawer.Title>
    <Drawer.Scroll>…</Drawer.Scroll>
  </Drawer.Content>
</Drawer.Root>;
```

## Coming from Sonner or Vaul

| You use | In Halo | Guide |
| --- | --- | --- |
| `toast()`, `toast.success`, `toast.promise`, `toast.dismiss` from `sonner` | The same calls from `halo-ui-react/toast` | [Migrate from Sonner](https://haloui.dev/docs/migrate/sonner) |
| `richColors`, `toastOptions` | `intent="tint"`, and `classNames` and `duration` on `<Toaster>` | [Prop by prop](https://haloui.dev/docs/migrate/sonner#mapping) |
| `Drawer.Root`, `Drawer.Content`, `snapPoints` from `vaul` | The same parts and snap points from `halo-ui-react/drawer` | [Migrate from Vaul](https://haloui.dev/docs/migrate/vaul) |
| `Drawer.Portal`, `Drawer.Overlay`, `direction`, `shouldScaleBackground` | Delete the portal and overlay; `side`; `recess` | [Prop by prop](https://haloui.dev/docs/migrate/vaul#mapping) |

Each guide lists what doesn't carry over, and has a prompt you can hand to a coding agent.

## What's different

- **Release velocity from the last 80 ms** of the gesture, handed to a closed-form spring, so motion continues your flick and can be interrupted.
- **Detents and dismissal by projection**: where the flick would coast to, not a fixed distance.
- **Transform and opacity only.** Nothing animates layout.
- **A native `<dialog>` drawer**: the top layer, focus trap and Esc come from the browser. No portal and no Radix.
- **Keyboard and screen readers**: polite and assertive live regions that announce each type, Alt+T to reach the stack, keyboard dismissal, and a drawer handle that is a real button. [Details](https://haloui.dev/docs/accessibility).
- **Four toasts you'd otherwise build yourself**: `toast.undo()`, `toast.stream()` for AI replies, `from` to launch out of a button, and `group` for repeats.
- **A popover with no positioning library**: the native popover API and CSS anchor positioning. It grows out of its trigger, and the light gathers where it attaches. [Popover](https://haloui.dev/docs/popover).
- **Swipe actions that work without a swipe**: every action is a real button, Tab slides the row open, focus moves on when a row leaves, and a flick on a closed row opens it instead of running an action. [Swipe actions](https://haloui.dev/docs/swipe).
- **Nine worlds**, each in light and dark, or your own in one CSS selector.
